
# Sales Analysis Dashboard – Power BI

## Project Overview
This project focuses on analyzing sales data using Microsoft Power BI to identify sales trends, business performance, and important insights.

## Objectives
- Analyze overall sales performance.
- Identify top-performing products.
- Understand monthly sales trends.
- Track revenue and business performance.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel
